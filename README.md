# To-Do-App

A colorful and interactive To-Do List web application built using **HTML, CSS, and JavaScript**.

This project helps users manage daily tasks with full CRUD functionality and local data persistence using `localStorage`.

---

## 🚀 Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- ☑️ Mark tasks as completed
- 🔍 Advanced Filters
  - All Tasks
  - Active Tasks
  - Completed Tasks
- 💾 Data saved automatically using `localStorage`
- 🎨 Colorful and responsive UI
- ⚡ Dynamic DOM manipulation
- 🧠 Event Delegation for better performance

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
